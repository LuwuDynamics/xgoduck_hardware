# XGO-Duck——整套 3MF 打印工程

[English](README.md) · **简体中文**

按机器人版本选择：**V5 为音视频版结构，V2 为原版结构**。工程包含整套模型、预排版打印盘及保存的打印设置，无需逐个下载和重新排布 STL。

## 选择版本并下载

| 机器人版本 | 工程文件 | 直接下载 |
| --- | --- | --- |
| **V5——音视频版** | `xgoduckV5.3mf` | [下载 V5 整套 3MF](https://raw.githubusercontent.com/LuwuDynamics/xgoduck_hardware/master/3DManufacturingFormat/xgoduckV5.3mf) |
| **V2——原版** | `XGO_duckV2.3mf` | [下载 V2 整套 3MF](https://raw.githubusercontent.com/LuwuDynamics/xgoduck_hardware/master/3DManufacturingFormat/XGO_duckV2.3mf) |

需要单个模型时，可使用 [V5 音视频版 STL](../structure/v5/README.zh-CN.md)（50 个，前缀 `V5_AUDIO_VIDEO_`）或 [V2 普通版 STL，无音视频](../structure/v2/README.zh-CN.md)（47 个，前缀 `V2_STANDARD_`）。每个带序号的文件对应原工程中的一个零件实例。请使用同一机器人版本对应的零件，不要混用不同版本的头部零件。

## 打开、核对、切片、打印

1. 下载对应版本的 3MF，在 **Bambu Studio 中作为项目打开**，保留已保存的分盘、排版和打印设置。
2. 核对实际使用的打印机、喷嘴、打印板及耗材分配。两个工程均保存了 **Bambu Lab P1P、0.4mm 喷嘴、0.20mm 层高**的配置，耗材设置包含 **PLA 和 TPU**。使用其他机型或材料时，应先选择匹配的设置。
3. 检查要打印的盘，保留原有零件摆放方向。重新排版前先查看原项目预览。
4. 各零件使用对应的 PLA 或 TPU 耗材；根据板卡版本**选择一种背包外壳**，轮滑套件按需打印。
5. 对选中的打印盘切片，检查走线预览后发送打印任务，或导出打印机支持的切片文件。

**这两个文件是可编辑的 3MF 项目，不包含已切片的 G-code，需要为实际打印机切片后再打印。保存的配置不代表已经验证适合所有机型和耗材。**

## 分盘说明

两个工程均保存了 9 个打印盘。两种背包外壳是供不同板卡选择的替代件，并不代表两个机器人版本。

### V5——音视频版

| 打印盘 | 保存的名称／用途 |
| --- | --- |
| 1–3 | PLA 零件 |
| 4 | TPU 零件；原盘名为 `TPU90-95` |
| 5 | V1 板卡背包外壳 |
| 6 | V1.1 板卡背包外壳 |
| 7 | PLA 零件 |
| 8 | 可选轮滑套件 |
| 9 | 外观遮盖零件 |

### V2——原版

| 打印盘 | 保存的名称／用途 |
| --- | --- |
| 1 | TPU 零件 |
| 2 | 黄色 PLA 零件 |
| 3 | 黑色 PLA 零件 |
| 4–6 | 模型零件；这三盘未保存盘名，请查看预览及耗材分配 |
| 7 | V1 板卡背包外壳 |
| 8 | V1.1 板卡背包外壳 |
| 9 | 可选轮滑套件 |

**V2、V5 是机器人结构版本，外壳名称中的 V1、V1.1 是 PCB 板卡版本。**请按实际[板卡](../PCBA/)选择外壳，无需同时打印两种外壳盘。

单个零件信息见[打印清单](../docs/PRINTING.md)，装配方法见[装配指南](../Assembly_Guide.pdf)。
