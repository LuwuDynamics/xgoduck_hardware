# Roadmap

[Project](readme.md) · [Community](COMMUNITY.md)

This is a proposed sequence of improvements, not a delivery schedule. Each milestone needs evidence before it is marked complete.

| Milestone | Current status | Completion evidence |
| --- | --- | --- |
| Understand the system | English documentation prepared locally | Published working links, lineage and clearly scoped licenses |
| Reproduce one build | Parts and assembly resources available; key details pending | Confirmed power/servo specifications, print profiles, mechanical-zero references and an independent build record |
| Reproduce the first motion | Runtime and three policies supplied; this documentation work did not test hardware | Fresh-board install log, calibration record, timing capture and continuous first-motion video |
| Evaluate custom policies | Training/export path documented | Versioned model card, compatible runtime and reported evaluation trials |
| Share community results | Issue/report templates prepared | Maintainer-reviewed builds and policy reports with permission to feature them |

## Good next experiments

Improved printability, clearer wiring diagrams, repeatable actuator characterization and documented calibration can benefit every builder. Additional motion tasks should be integrated and evaluated individually rather than promoted merely because a simulator task exists.

Potential future work includes a validated XGO-Duck browser demo, a tested build-profile library and a catalog of compatible policies. These are proposals, not currently available services. Upstream feature parity and a specific release date are not promised.

To propose work, describe the user benefit, smallest useful change, compatibility impact and evidence that would establish success.
