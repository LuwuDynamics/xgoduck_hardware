# Cece Bambu Studio print preparation

This 3MF is the PLA H2S prototype layout prepared from the current candidate parts, with 0.20 mm layers, 2 walls, 15% infill and automatic tree supports limited to critical regions. The design and attachment hardware have not been physically validated; it is not a verified walking robot or a final print release. The estimated slicer output was 150.7 g including supports and 5 h 14 min.
