# Experiments

- [`xgoduck/`](xgoduck/) contains the XGO-Duck FreeCAD reference, simulation
  scripts and results, print-weight estimate, and the design review.
- [`otto/`](otto/) archives a separate four-servo Otto reference, Cece prototype,
  and head-turning simulation experiment.

The original XGO-Duck hardware and print files remain in the repository's
`structure/`, `PCBA/`, documentation, and assembly guide. The experimental
models have not been validated as completed physical robots. In particular,
the Cece head servo mount, electronics fittings and head/body clearance remain
unfinished. See each experiment's README and source attribution before use.
