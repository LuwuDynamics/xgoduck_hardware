# XGO-Duck printable STL files

These 27 STL files are the normal non-roller print set copied from
[`../structure/`](../structure/). At the time this folder was added, each file
was verified byte-for-byte against that directory. The upstream `structure/`
directory remains the primary source; this folder provides the simple `3d/`
location requested for the project. Changes in either folder are not synced
automatically.

Files beginning with `2x_` are generally printed twice; `_tpu` denotes
flexible parts. The upstream inventory and actual filename disagree for
`2x_hip_yaw2rol.STL`, so confirm its quantity against the assembly guide.
Optional roller-skate files remain in `structure/` and are not copied here.

See the upstream [printing inventory](../docs/PRINTING.md),
[assembly guide](../Assembly_Guide.pdf), [licensing notes](../LICENSING.md),
and our [weight estimates](../experiments/xgoduck/xgoduck_print_inventory/PRINT_WEIGHT_TABLE.md).
